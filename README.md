# TLC 的个人网站

一个轻量、响应式的中文个人主页，使用原生 HTML、CSS 和少量 JavaScript，无需安装依赖或构建工具。

## 本地预览

直接在浏览器中打开 `index.html` 即可。

## 发布到 GitHub Pages

在仓库的 **Settings → Pages** 中，将部署来源设为 `Deploy from a branch`，选择 `main` 分支和 `/ (root)` 目录并保存。部署完成后，GitHub Pages 会提供网站访问地址。

## 个性化

编辑 `index.html` 中的自我介绍、兴趣、作品与联系链接。当前页面中的姓名使用 TLC，联系入口指向 GitHub 账号 `tlc680705`。
